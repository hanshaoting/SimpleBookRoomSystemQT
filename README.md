# SimpleBookRoomSystemQT

本项目是一个基于 C++ 和 Qt 框架开发的本地桌面端图书管理系统。系统采用面向对象编程（OOP）思想构建，实现了核心的图书借还逻辑、读者信息管理以及轻量级的本地数据持久化功能。

## 技术栈

* **编程语言**：C++ (支持 C++11/17 标准)
* **GUI 框架**：Qt 5 / Qt 6 (QtWidgets)
* **核心机制**：Qt 信号与槽（Signals and Slots）、文件 I/O (QFile, QTextStream)
* **数据结构**：Qt 容器类（QVector）

## 系统架构与核心类

项目在业务逻辑层抽象了四个核心实体类，通过相互嵌套与调用实现对实体数据的封装与管理：

* `Library`：系统的顶层管理类，作为数据总入口，维护 `Books` 列表和 `reader` 列表，提供全局的增删改查及文件读写接口。
* `Books`：描述单一书目（SPU）的元数据（书名、编号、作者、出版社等），内部嵌套一个 `Register` 的 QVector 容器，用于管理同名书籍的多个实体复本。
* `Register`：描述单册实体书（SKU）的借阅状态（独立登记号、是否借出、借书证号、借阅时间）。
* `reader`：描述读者实体信息（借书证号、姓名、性别、联系方式）。

## 核心功能

1.  **图书资产管理**：支持管理员录入新书信息（自动为单册书生成独立登记号），并支持按书名或编号删除书籍。
2.  **读者档案管理**：支持录入新读者的基本信息及借书证号。
3.  **借还书业务处理**：
    * **借书**：校验系统内对应书目是否有未借出的闲置实体书，若有则绑定读者借书证号并更新借出状态。
    * **还书**：支持通过精准的“实体书登记号”一键归还，自动解除绑定关系并恢复可借阅状态。
4.  **多维数据查询**：支持查询特定书目的基础信息、某单册书的当前借阅状态，以及特定读者的历史借阅记录。
5.  **本地数据持久化**：自定义文本序列化规则，通过本地 `.txt` 文本文件实现所有图书数据及借阅记录的保存与恢复。

## 编译与运行

1.  环境要求：安装配置好 Qt Creator 及配套的 MinGW / MSVC 编译器。
2.  克隆或下载本项目源码。
3.  使用 Qt Creator 打开 `library.pro` 项目文件。
4.  配置 Kit 并点击构建（Build），运行生成的独立可执行文件。
